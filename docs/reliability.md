# 采集、复核与发布边界

本公开版只支持智联和猎聘，候选人事实由使用者在本机配置。仓库中的测试全部使用虚构资料，不分发个人履历、真实岗位清单、运行记录或浏览器授权。

## 同日读取与失败

缓存分别保存读取结果和尝试状态。成功项复用；超时、失败或中断中的请求默认拒绝自动重访。只有明确恢复时才启用重试失败项，同时仍复用成功项。网络超时不能证明请求尚未发送。

智联验证与正式采集共享同日搜索和详情缓存。验证保存连接、搜索、编号稳定性和详情阶段进度。登录、安全验证、网络或页面结构错误停止该来源。猎聘不同搜索词轮流进入既有详情预算，避免单一标题类型占满预算。

## 候选池与展示

准备文件保存完整已评分候选池；最终输出按使用者的阈值、谨慎名额和猎头比例选择。未展示不等于被判不符合。单平台按稳定职位编号去重，跨平台重复保留标注。

必需条件与加分项分开处理。AI年限不足或产品年限证据不足列待核对；独立生产研发、全栈工程、专业运维及明确行业硬要求不能由工具关键词或AI辅助原型代替。默认更新时间排除线为30天；未知日期不以招聘者活跃时间或本机首次收录时间替代。高级配置字段`max_job_update_age_days`接受0—3650，0表示关闭该日期排除线。

完整JD指纹覆盖全文。同岗位、同全文及同招聘者类型的已有话术可以保留。人工复核可在候选记录的`manual_review`中保存`decision`（`exclude`或`cautious`）、`reason`和`fingerprint`；正文改变后重新核对，谨慎复核不能覆盖新发现的明确不符条件。

`rescore_saved_report`接受可选`prepare_output`：指定后仅准备候选，不覆盖已发布日报。未指定时重新生成对应日期HTML、JSON和数据库记录，并沿用该期来源快照。

## 验证

Python回归检查使用虚构履历、岗位和故障；扩展使用本机模拟页面检查。发布前执行`python tools/security_checks.py --release`，核对Git实际跟踪清单，阻止私人目录、文档、数据库、日志和本机配置误上传。

离线检查不能保证招聘网站永久稳定，也不等于已测试关机恢复、实际登录过期或新一轮联网采集。访问限制和登录仍应在平台官方页面处理。
